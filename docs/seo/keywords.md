# Mapa de palabras clave

Investigación del 23 de octubre de 2026. No hay datos públicos de volumen por ciudad, así que el mapa se basa en las palabras que usan las agencias que hoy salen en Google para Medellín, y en las preguntas reales de clientes. Cuando haya Search Console y Google Keyword Planner, se ajusta con datos propios.

Fuentes consultadas: agencias que posicionan "páginas web Medellín" (sioncreativos.com, paginas-web.com.co, luisguerra.co, cangrejodigital.com), guías de reservas para belleza (agendapro.com), menús digitales y pedidos para restaurantes (Portafolio, El Colombiano, La Nota Económica), catálogos por WhatsApp (Xataka, Leadsales), chat con IA y WhatsApp en Colombia (Enter.co, Portafolio, El Tiempo), mantenimiento web (Hostinger, Seahawk), Shopify y WooCommerce frente a pasarelas colombianas (Cangrejo Digital, comunidad Shopify).

Hallazgos que cambian el texto:
- En Colombia el cliente prefiere escribir antes que llamar: WhatsApp es el canal favorito de 3 de cada 4 personas (Enter.co). Todo llamado a la acción va a WhatsApp.
- Muchos negocios de salud y belleza todavía agendan por teléfono o call center. La reserva en línea es el gancho de esas páginas.
- Wompi no se integra con Shopify (comunidad Shopify). Con código propio sí se puede usar Wompi, Mercado Pago, PayU o Stripe. Es un argumento real para tiendas a la medida.
- En Google Maps pesan relevancia, distancia y prominencia (reseñas, menciones). Base del texto de SEO local.
