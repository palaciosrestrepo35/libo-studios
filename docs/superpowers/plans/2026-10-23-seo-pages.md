# LIBO STUDIOS SEO Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the one-page LIBO STUDIOS site into 20 pages (home + 19), each fully optimized for Google, in plain Spanish, all sharing the home page's look.

**Architecture:** Page bodies live in `pages/` as HTML fragments with a JSON header. A zero-dependency Node script, `tools/build.mjs`, wraps each one in a shared layout and writes plain static files (`<slug>/index.html`, `sitemap.xml`). The output is committed, and Vercel serves it as-is, so there's still no build on Vercel. `tools/check.mjs` lints every built page for SEO, links and copy rules. Shared CSS and JS move out of `index.html` into `styles.css` and `site.js`. The home page stays hand-written.

**Tech Stack:** HTML, CSS, vanilla JS, Node 24 (local only, no npm packages). GSAP 3.13 from jsDelivr is allowed (already used). reactbits components are allowed, ported to vanilla JS the way `motion.js` already does (no React).

**Spec:** `docs/superpowers/specs/2026-10-23-seo-pages-design.md`

## Global Constraints

- Base URL in exactly one place: `BASE = 'https://libo-studios.vercel.app'` in `tools/build.mjs`. `index.html` hard-codes it too; `check.mjs` verifies they match.
- All copy in Spanish, plain words for a business owner. No em dash (—) or en dash (–) anywhere in copy.
- Banned client-facing jargon in visible text (not in JSON-LD): `Core Web Vitals`, `Merchant Center`, `HSTS`, `HTTPS`, `API`, `APIs`, `SSL`, `CRM`, `indexación`, `indexadas`, `SEO técnico`, `datos estructurados`, `Cloudflare`, `UX/UI`, `landing page` (use "página de campaña" or "página para tu campaña").
- No prices, no invented clients, numbers, reviews or testimonials. Only Detalles de Amor as past work. Every other page speaks in capability ("construimos", "podemos construir").
- WhatsApp `573154192623`, email `palaciosrestrepo35@gmail.com`, city Medellín, "todos los días, 24/7".
- Medellín in main titles; Colombia (Bogotá, Cali, Barranquilla...) and international clients in body copy.
- Small businesses and big companies, said explicitly on Estudio, Servicios and Desarrollo a la medida.
- Every page: unique `<title>` ≤ 60 chars, meta description 120 to 160 chars, exactly one `h1`, canonical, OG + Twitter tags, JSON-LD (BreadcrumbList + page type), link back home, header and footer identical to the layout.
- Home page must look and behave exactly as before (intro video, WebGL hero, wheel, animations), apart from nav links and the copy changes listed in Task 7.
- `prefers-reduced-motion` respected; no new animation runs without it being honored.
- Inner pages do not load `acid.js` or the intro video.

### Task 1: Build and check tooling, proven on Contacto

**Files:**
- Create: `tools/build.mjs`, `tools/check.mjs`, `tools/build.test.mjs`, `pages/contacto.html`
- Output: `contacto/index.html`, `sitemap.xml`

**Interfaces:**
- Produces, page source format: file starts with `<!--{json}-->` then the body HTML (one or more `<section>`). JSON fields:
  - `title` (string, full `<title>`)
  - `description` (string)
  - `crumbs` (array of `[name, path]`, excluding Inicio and the page itself)
  - `name` (short page name, for breadcrumb and nav highlight)
  - `schema` (array of JSON-LD objects, optional)
  - `og` (image path, optional, default `assets/og/default.jpg`)
  - `nav` (one of `estudio|servicios|proyectos|sectores|proceso|contacto`, optional, marks `aria-current="page"`)
  - `form` (boolean, include the quote form script)
- Produces, `tools/build.mjs`: exports `BASE`, `parsePage(text, file) -> {meta, body}` (throws `Error` naming `file` on bad JSON or missing `title`/`description`/`name`), `urlFor(file) -> '/x/y/'`, `render(meta, body, url) -> html string`, `sitemap(urls) -> xml string`. Running `node tools/build.mjs` builds every file under `pages/` and writes `sitemap.xml` (home + all pages except 404).
- Produces, `tools/check.mjs`: `node tools/check.mjs` scans `index.html` and every built page and exits 1 listing every violation of the Global Constraints that can be checked mechanically: title length, description length, single h1, canonical equals `BASE + url`, JSON-LD parses, internal `href`s resolve to a file, banned jargon and dashes in visible text, `BASE` in `index.html` matches, every built page listed in `sitemap.xml`.
- Layout `render` includes: the `<head>` from `index.html` (charset, viewport, fonts, favicon) plus `styles.css`, canonical, OG/Twitter, JSON-LD (BreadcrumbList generated from `crumbs` + `schema`), the header with nav links to the 6 pages (`/estudio/` ...), CTA button "Cotizar proyecto" → `/contacto/`, a visible breadcrumb `<nav aria-label="Ruta">`, `<main>` with body, the footer (columns: brand; Servicios links to the 7 service pages; Estudio links to the 6 nav pages; Contacto block as on home), the floating WhatsApp button, `site.js`.
